# Glasscii

برنامج لويندوز يحوّل الصور وGIF إلى ASCII وHalftone وDiamonds وVoxels، ويعرض النتيجة كويدجت تفاعلي على سطح المكتب دون الحاجة إلى تصدير.

## المميزات

- الألوان الأصلية أو الرمادي، مع حروف ASCII يختارها المستخدم.
- التحكم بحجم الخلية وBrightness وHighlights وBlack point وعكس الدرجات.
- سرعة GIF قابلة للتعديل.
- أكثر من ويدجت مستقل، مع التسمية وحفظ المواقع والإعدادات.
- خلفية شفافة وتأثير زجاج وصبغة قابلة للتعديل، وإمكانية إخفاء الإطار والأزرار.
- ساعة وتاريخ بخطوط وألوان وأحجام وتنسيقات قابلة للتخصيص.
- Presets لحفظ الشكل وتطبيقه لاحقًا.

## التشغيل

للاستخدام العادي حمّل `Glasscii.exe` من قسم Releases وافتحه مباشرة؛ لا تحتاج Python.

لتشغيل الكود، ثبّت Python 3.11 أو أحدث، ثم افتح PowerShell داخل مجلد المشروع:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

ملفات `ui` و`engine` وحدات محلية ضمن المشروع وليست مكتبات خارجية.

## الاستخدام

افتح صورة أو GIF، اختر الستايل والألوان وعدّل البارات، ثم أظهر الويدجت. حجم الخلية الأصغر يزيد التفاصيل وكلفة الرسم. يمكن إضافة صورة أو ساعة جديدة من أدوات الويدجتات أو قائمة أيقونة البرنامج قرب الساعة.

عند إخفاء الإطار، تبقى مساحة عناصره محفوظة لتجنب تغيّر الحجم والاهتزاز. لاستعادة الإطار اضغط بزر الفأرة الأيمن على الويدجت واختر Show frame، أو افتح Settings من أيقونة البرنامج. للخروج الكامل اختر Quit.

الإعدادات والقوالب محفوظة محليًا عبر QSettings. استعادة الصورة تحتاج بقاء ملفها الأصلي في موقعه. يتوقف GIF مؤقتًا إذا كانت نافذة إعداداته وويدجته مخفيتين أو مصغرتين معًا.

## بناء EXE

نفّذ على ويندوز:

```powershell
.\.venv\Scripts\python.exe -m pip install "PyInstaller>=6,<7"
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name Glasscii --icon icon.ico --add-data "icon.ico:." app.py
```

النتيجة داخل `dist/Glasscii.exe`. أعد البناء بعد تعديل الكود. ملف الأيقونة مضمّن لأيقونة EXE والواجهة وقائمة النظام.

## الاختبارات

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

الاختبارات الحالية تفحص ثبات الإطار والتخطيط واختيار الويدجت الصحيح من قائمة النظام. تستخدم عرض Qt افتراضيًا وإعدادات مؤقتة؛ تأثيرات ويندوز وأيقونات النظام تحتاج اختبارًا على ويندوز.

## للتطوير

ابدأ من `engine.py` لفهم أخذ العينات، ثم `renderer.py` لفهم تحويلها إلى حروف وأشكال. الواجهة في `ui.py`، وخلفيتها المرسومة وتوهج الماوس في `ui_motion.py`. إدارة الجلسات بقائمة النظام في `workspace.py`، وتفاعل الرسم في `interaction.py`.

أخذ العينات منفصل عن الرسم: تغيير حجم الخلية يحتاج تحميل عينات جديدة، بينما تغيير اللون والسطوع يعيد الرسم من البيانات الموجودة. تحميل الصورة ورسم الإطارات يستخدمان خيوط عمل، ثم تُرسل النتيجة إلى خيط الواجهة بواسطة signals. حدود الإطارات والبكسلات تمنع استهلاك الذاكرة بلا حد.

الأداء يعتمد على حجم الويدجت وكثافة الخلايا وعدد الويدجتات. دعم الزجاج يعتمد على إصدار ويندوز. للتبليغ عن مشكلة اذكر إصدار ويندوز وطريقة التشغيل والستايل وحجم الخلية وخطوات تكرار الخطأ.
