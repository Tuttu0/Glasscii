# Glasscii v1.0.0

First public release of Glasscii for Windows.

- Convert images and animated GIFs to ASCII, Halftone, Diamonds, and Voxels.
- Use original colors or grayscale, custom ASCII characters, and tone controls.
- Place multiple transparent widgets on the desktop, with optional glass styling.
- Customize clock/date widgets and save appearance presets.
- Interact with artwork using the mouse.

## Download

Download `Glasscii.exe` from the assets below and double-click it. Python is not required.

Right-click a widget or use the tray icon for settings. Choose **Quit** in the tray menu to exit completely.

Windows is the primary platform. Native glass appearance and rendering performance depend on the system and selected settings.
